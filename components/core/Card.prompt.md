General-purpose content surface — product cards, feature blocks, testimonials. Thick ink border, big radius, soft shadow, gentle hover lift.

```jsx
<Card accent="var(--color-mint-green)">
  <h3>Nose Soap Dispenser</h3>
  <p>Snot your regular soap dispenser.</p>
</Card>
```

Set `hoverable={false}` for cards inside a grid that shouldn't animate (e.g. behind a modal). `accent` adds a colored top stripe for category coding.
