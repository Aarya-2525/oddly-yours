Pill-shaped CTA button with a thick ink border and a hard drop-shadow that collapses on press — use for primary actions, add-to-cart, nav CTAs.

```jsx
<Button variant="primary" size="md">Get the kit</Button>
<Button variant="ink" size="sm">Learn more</Button>
```

Variants: `primary` (bubblegum pink), `secondary` (cream), `ink` (dark), `ghost` (text-only, no shadow). Sizes: `sm`, `md`, `lg`. Pass `icon` for a leading glyph. `disabled` removes the shadow and dims the button.
