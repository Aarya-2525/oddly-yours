Badge is a static pill label (status, category). Tag is a clickable filter chip that scales and tilts on hover.

```jsx
<Badge color="mint">New</Badge>
<Tag color="pink" selected>Décor</Tag>
```

Badge colors: pink, blue, mint, lavender, yellow, orange, ink. Tag colors: pink, blue, mint, lavender, yellow. `selected` fills the Tag with its color; unselected Tags stay cream with an ink border.
